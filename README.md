### Forward Deployed Engineer

I take AI from demo to production inside operating businesses: voice agents on live phone lines, agents wired to tools that move money and change calendars, and retrieval that cites its sources or refuses.

#### How I build

- Rules that touch money, calendars or customer records live in code, not in prompts.
- Every value an agent presents declares where it came from.
- Releases ship behind tests, evals wherever a model is involved, and a ready rollback.
